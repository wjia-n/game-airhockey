# Air Hockey

Air Hockey by Wajiha — a fast, physical arcade air-hockey game for Android.
Drag your mallet, smack the puck, first to 7 goals wins.

- Solo vs AI (Rookie / Skilled / Champion) or 2-player local pass-and-play
- 12 table themes + custom theme creator, 8 mallet styles, 8 puck styles
- Synthesized music & SFX (no asset files), pause/resume on lifecycle
- Pro unlock + tip jar via Play Billing
  (`airhockeypro`, `airhockeycoffee`, `airhockeychocolate`)

Package: `com.gameswajiha.airhockey`

## Getting Started

Standard Flutter app. CI builds release APK + AAB on manual dispatch
(`.github/workflows/build.yml`), signed with the shared upload key.

For help getting started with Flutter development, view the
[online documentation](https://docs.flutter.dev/), which offers tutorials,
samples, guidance on mobile development, and a full API reference.
